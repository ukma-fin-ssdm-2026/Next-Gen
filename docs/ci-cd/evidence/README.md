# Докази запусків CI/CD (Лабораторна робота 10)

У цьому каталозі зберігається вивантажений з GitHub Actions REST API набір даних для всіх **60 одиниць постачання** (**120 запусків** робочих процесів `CI` і `Deploy API docs`) на гілці `main` за період **2026-10-30 — 2026-11-13** включно.

- [`main-runs-2026-10-30-to-2026-11-13.json`](main-runs-2026-10-30-to-2026-11-13.json) — структурований JSON-експорт:
  - `metadata` — параметри репозиторію, період спостереження та контрольні підсумки (`60` одиниць, `120` запусків);
  - `delivery_units` — 60 згрупованих одиниць постачання, кожна з точними мітками часу (`first_commit_at`, `completed_at`), тривалістю очікування в черзі (`queue_seconds`) та виконання (`execution_seconds`), підсумковим статусом і масивом пов'язаних запусків `workflow_runs`;
  - `github_runs_raw` — сирі поля запусків GitHub Actions (`databaseId`, `workflowName`, `headSha`, `status`, `conclusion`, `attempt`, `createdAt`, `runStartedAt`, `updatedAt`, `url`) для кожного із 120 запусків.

## Як відтворити та перерахувати метрики

```bash
python scripts/calculate_dora_metrics.py
```

Для повторного вивантаження актуальних запусків із GitHub Actions API:

```bash
python scripts/calculate_dora_metrics.py --fetch-github
```
