# Тестове наповнення каталогу

Для ручної перевірки пагінації, фільтрів і вигляду каталогу в репозиторії є
службовий CLI-скрипт [`scripts/seed_listings.py`](../../scripts/seed_listings.py).
Він створює задану кількість повноцінних оголошень у PostgreSQL, генерує для
кожного валідне JPEG-зображення, зберігає оптимізовані файли у налаштованому
сховищі та позначає назви префіксом `[SEED]`.

Скрипт не є публічним API-ендпоінтом і не обходить мережеву авторизацію
застосунку. Це окрема команда обслуговування, яку запускає оператор у
контрольованому середовищі з доступом до `DATABASE_URL` та
`IMAGE_STORAGE_DIR`.

## Передумови

1. Схему PostgreSQL оновлено командою `alembic upgrade head`.
2. Майбутній власник оголошень хоча б один раз увійшов у систему, тому його
   локальний профіль уже існує в БД.
3. Перед запуском на середовищі з важливими даними створено резервну копію.

## Запуск у Docker Compose

Після додавання скрипта до образу його можна запустити всередині контейнера
API. Приклад створення 20 оголошень:

```bash
docker compose exec api python -m scripts.seed_listings \
  --owner-email student@ukma.edu.ua \
  --count 20
```

За замовчуванням використовується перша активна категорія. Конкретну категорію
можна вибрати за `slug`:

```bash
docker compose exec api python -m scripts.seed_listings \
  --owner-email student@ukma.edu.ua \
  --count 20 \
  --category-slug electronics
```

## Локальний запуск без контейнера API

Якщо `DATABASE_URL` та `IMAGE_STORAGE_DIR` уже задані в поточному середовищі:

```bash
python -m scripts.seed_listings \
  --owner-email student@ukma.edu.ua \
  --count 20
```

Команда працює на будь-якому хості, який має доступ до потрібної PostgreSQL і
сховища зображень; вона не прив'язана до конкретного сервера.

## Очищення тестових даних

Очищення видаляє лише оголошення зазначеного власника, назви яких починаються
з `[SEED]`, а також пов'язані з ними файли зображень. Прапорець `--yes`
обов'язковий, щоб уникнути випадкового запуску деструктивної операції:

```bash
docker compose exec api python -m scripts.seed_listings \
  --owner-email student@ukma.edu.ua \
  --cleanup \
  --yes
```

Скрипт призначений для підготовки демонстраційних даних. Він не замінює
навантажувальне тестування: конкурентні запити до розгорнутого API потрібно
виконувати окремим інструментом, наприклад k6 або Locust.
