> - **Інструменти:** Claude, Gemini, OpenAI Codex.
> - **Етап:** Побудова матриці простежуваності (RTM), зв'язок user stories з FR/NFR (Лаб 2) та актуалізація для Лабораторної 7 і нових функціональних вимог FR-013–FR-015 (`TP-001`–`TP-028`, `DT-01`–`DT-07`, `TP-N01`, `TP-N02`, `TP-AUTH-01`–`TP-AUTH-04`).
