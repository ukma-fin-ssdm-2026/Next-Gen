## Branching Strategy - GitHub flow

- `main` contains stable code.
- New work is done in separate branches.
- Changes are merged into `main` through Pull Requests.
- Direct pushes to `main` are restricted.
## Workflow

1. Беремо задачу з Issues
2. Створюємо гілку: `feature/номер-issue-коротка-назва`
3. Робимо Pull Request
4. Хтось з команди перевіряє
5. Зливаємо в main
